# gerador-cracha-js
O objetivo do código do trabalho do gerador de crachá, é revisar e aplicar o conceitos das unidades 1 a 5 da disciplina de Lógica da programação, o gerador de crachá usa o html com a linguagem de Javascript e conversão de dados e variáveis do código e formatação no console com o objetivo de criar um sistema que analisa nome, sobrenome, idade e status estudantil do usuário e organizá-los de modo a criar um crachá virtual estudantil. O projeto também serviu para ensinar a colaboração em equipe em caso de futuro cenário de colaboração com outros programadores em nossas carreiras se seguirmos esse caminho, além de também nos ensinar a trabalhar usando o github sem estar no mesmo local que nossos parceiros de trabalho.
